# 임베디드 학습 위키

현대 AI 인사이트 캠퍼스 강의 정리 위키. 배운 순서대로
컴퓨터 구조 → 운영체제 활용 → Python → C → LINUX → MCU → Embedded IO → Neural Network.
과목 목록·교안 경로는 `tools/build_site.py` 의 `SUBJECTS` 한 곳에서 관리한다 (새 과목은 여기에 한 줄 추가).
교시마다 **정리 노트 · 예제 코드(+빌드·실행) · 강의 개념 목록 · 연관 문제**를 한 페이지에 모으고,
모르는 개념은 검색해서 **정의와 처음 나온 교시**로 바로 이동한다.

- 사이트: GitHub Pages (Settings → Pages → Branch `main` / root)
- 로컬 확인: `index.html` 을 브라우저로 열면 된다 (서버 불필요)

## 교시 페이지 구성

| 영역 | 출처 | 내용 |
|---|---|---|
| 정리 노트 | `notes/<과목>_dayN.md` (직접 작성 · 없으면 `~/c_study/summary/.src`) | 키워드 → 개요 → 핵심 용어 → 새로 나온 함수 → 예제 코드가 하는 일 → 핵심 내용 → 기본 사용형태 → 연결 |
| 강의 원문 | `lecture.html` · `.ipynb` · `.pptx` (자동 추출 — html 은 `lecture_parse.py`, 노트북·슬라이드는 `nbparse.py`) | 강의 원문을 주제(h3)별로, 읽음 체크 |
| 오른쪽 💻 코드 | `lecture.html` + 노트 표 | 과목 → Day → 교시 → 예제 목차. 원본 파일명 · 무엇을 보나 · 핵심 개념 + 코드 · 빌드·실행 · 결과 |
| 오른쪽 📖 사전 | 노트의 핵심 용어 · 새로 나온 함수 | 용어·코드 통합 목록, 본문과 나란히 검색 |
| 연관 문제 | `worksheet.html` (자동 추출) | 보기 클릭 채점, 퀴즈 페이지에서 오답 노트 |

## 같은 개념 연결

노트를 따로 표시하지 않아도 `assets/concepts.js` 가 교시 안에서 자동으로 잇는다.

- **개념** = 핵심 용어 + 새로 나온 함수·명령. 이름(괄호 속 영문, `a / b` 도 각각)이 검색 키
- 키가 나오는 **핵심 내용 글머리 · 사용형태 코드 줄 · 강의 예제 코드 · 강의 토픽 · 문항**을 모은다
- "예제 코드가 하는 일" 표의 행은 `1-2`, `2_errno.c`, `01_blink.c` 같은 번호·파일명으로 강의 예제(💻 코드 패널)와 짝짓는다
- 화면: 글머리 끝의 점선 칩(개념)·▶ 칩(예제)을 누르면 **옆 패널**에 정의·핵심 내용·코드·문항이 모인다.
  정리 노트 제목 옆 **개념별 묶어 보기**는 노트를 개념 카드(정의 + 그 개념의 글머리 + 사용형태 + 예제 코드)로 재배치한다
- 주소로 열기: `#/c/2/7?p=c:f2` (개념 패널), `?p=x:3` (💻 코드 패널), `?v=concept` (개념별 보기)
- 연결이 안 잡히면 핵심 용어 이름을 본문과 같은 표현으로 쓰거나 괄호에 별칭을 넣는다: `**메모리 누수(memory leak, 누수)**`

## 노트 작성 규칙 (`summary/.src/*.md`)

```markdown
## Day N — 제목

### M교시 · 제목

**키워드**: `용어1`, `용어2`, …          ← 검색 칩
**개요**: 한 단락
**핵심 용어**
- **용어(영문)**: 정의               ← 용어 사전으로 자동 수집
**새로 나온 함수**                    ← (함수/명령/것 모두 인식) 표의 첫 칸 = 함수·명령 사전
| 함수 | 기본형 | 용도 |
**예제 코드가 하는 일**
**핵심 내용**
**기본 사용형태**
**연결**
- [C D3·5교시 volatile](#/c/3/5) — 왜 이어지는지   ← 과목 연결 지도로 수집
**연관 문제**
<<QA M>>                              ← worksheet M교시 문항
```

## 내용 보강 데이터 (`summary/.src/`)

| 파일 | 형식 | 화면 |
|---|---|---|
| `api_detail.json` | `"sched_getaffinity": {role, args: [[인자, 한글 뜻]…], flow, ret, hdr}` — 키는 함수 표 이름 그대로 · 첫 낱말 · 괄호 앞 식별자 | 사전 항목, 교시 함수 표 '인자 · 동작', 큰 개념 카드, 용어 패널 |
| `code_guide.json` | `"linux/2/04_affinity.c": [{at, to, t, d}…]` — at/to = 블록 첫·끝 줄에 들어 있는 글자 | 💻 코드 패널: 단계마다 그 줄들을 미리 색칠, 칠해진 곳을 누르면 블록 아래에 설명 팝업 (위 '🧭 코드 읽기 가이드' 는 접힌 단계 목록) |

- 두 파일 모두 `api_detail.mcu3.json` · `code_guide.eio4.json` 처럼 **나눠 써도 된다** (`이름.*.json` 을 전부 합침, 키 `_설명` 만 무시).
- 같은 Day 에 같은 파일 이름이 두 교시에 있으면 키에 교시를 넣는다: `"c/1/3/main.c"` · `"c/1/8/main.c"` (없으면 `"c/1/main.c"`).
- at/to 는 **한 줄 안의 글자**여야 하고, 단계는 위에서 아래로 겹치지 않게 (다음 단계는 앞 단계의 to 뒤에서 찾는다).
- 함수 색인은 노트 "새로 나온 것" 표에서 모으되, 머리글 행과 첫 머리글이 비었거나 `Day · 설정 · 분류 · 모드 · 구성 · 값 · 필요` 인 표(일정·설정·비교 표)는 뺀다.
- 표 칸 안 코드에 `|` 를 쓰려면 `\|` 로 (안 그러면 칸이 갈라진다).

빌드 때 가이드의 at/to 를 못 찾으면 `! 코드 가이드 단계 못 찾음` 경고가 뜬다.

## 복습 퀴즈 (Google 설문지)

```bash
python3 -I tools/reviewquiz.py "<복습퀴즈 폴더>"   # 저장한 .html → summary/.src/review_quiz.json
python3 -I tools/build_site.py
```
- 채점 결과 화면을 저장한 파일은 **공식 정답 · 해설 · 교시**(`[복습: D2-3 …]`)를 그대로 쓴다 → 배지 `복습`
- 채점 전 화면(정답 없음)은 `summary/.src/review_quiz_answers.<과목><Day>.json` 의 `[교시, 정답 번호(0부터), 해설]` 로 채운다 → 배지 `복습 · 직접 풀이` (공식 아님)
- 교시 문항은 worksheet 뒤에 붙는다 (오답 기록 번호 유지)

## 빌드

```bash
python3 -I tools/build_site.py          # 전 과목 → data/*.js
python3 -I tools/build_site.py c linux  # 일부만
git add -A && git commit -m "…" && git push
```

원본 경로 기본값은 `~/c_study` (`AI_CAMPUS/` 강의·워크시트, `summary/.src/` 노트). 바꾸려면 `STUDY_ROOT=… python3 -I tools/build_site.py`.

| 파일 | 역할 |
|---|---|
| `tools/build_site.py` | 노트·강의·워크시트 → `data/index.js`(목차·검색 색인·사전) + `data/<과목>.js`(교시 본문) |
| `tools/lecture_parse.py` | `lecture.html` 의 `secN` = N교시, `h3` = 토픽, `pre` = 코드(코드/명령/출력 분류). 빈칸 문제(`h4.fill` 이후)는 제외 |
| `tools/wsparse.py` | `worksheet.html` 의 `const Q=[…]` 문항 파서 |
| `assets/app.js` | 해시 라우팅 SPA (교시·검색·용어/함수 사전·연결·퀴즈) |
