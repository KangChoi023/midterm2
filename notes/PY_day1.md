## Day 1 — Colab 환경과 Python 기초

### 1교시 · Colab 시작하기

**키워드**: `Colab`, `셀 실행 순서`, `!`, `%`, `%%`, `Drive 마운트`, `#@param`

**개요**: 노트북은 셀 단위로 실행되고, 실행한 순서가 커널의 변수를 만든다. `!` 는 리눅스 셸, `%` · `%%` 는 노트북 매직. `/content` 는 세션이 끝나면 사라지므로 남길 파일은 Drive 에.

**핵심 용어**
- **커널(kernel, 노트북)**: 셀 코드를 실행하고 변수를 기억하는 Python 프로세스. 런타임 재시작 시 변수가 모두 사라진다
- **매직 명령(magic)**: `%` 한 줄, `%%` 셀 전체에 적용되는 IPython 명령 (`%timeit`, `%%writefile`)

**핵심 내용**

#### 셀 실행 순서 = 변수
> 위치가 아니라 실행한 순서 — 셀 왼쪽 `[n]` 이 실행 번호
- **재시작 후 두 번째 셀만** → `NameError` (앞 셀의 변수가 없다)
- **재시작 후 남는 것** → 화면의 코드와 옛 출력뿐

#### `!` vs `%`
- **`!ls`** → 리눅스 셸에 그대로 전달
- **`%timeit`** · **`%%writefile hello.py`** → Colab(IPython)이 처리
- **Drive** → `/content/drive/MyDrive` 에 저장해야 남는다
- **`#@param`** → `input()` 대신 입력 폼

### 2교시 · 변수와 자료형

**키워드**: `이름표`, `int`, `float`, `bool`, `str`, `None`, `type()`, `형변환`, `f-string`

**개요**: 변수는 값을 담는 상자가 아니라 값에 붙인 이름표. int 는 자릿수 제한이 없고 float 는 오차가 있다. 형변환 실패는 ValueError.

**새로 나온 함수**
| 함수 | 기본형 | 용도 |
|---|---|---|
| `type()` | `type(3.5)` | 자료형 확인 |
| `int()` · `float()` · `str()` | `int("42")` | 형변환. `int("3.5")` 는 ValueError |
| f-string | `f"{v:.2f}"` · `f"{n:08b}"` · `f"{n:#x}"` | 자릿수 · 정렬 · 진법 지정 |

**핵심 내용**

#### 변수 = 이름표
> `b = a` 는 같은 객체에 이름표를 하나 더 붙인 것
- **재대입** → 이름표를 다른 값으로 옮김

#### 자료형의 성질
- **int** → 자릿수 제한 없음 (C 의 int32 와 다름)
- **float** → IEEE 754 오차 — `0.1 + 0.2 != 0.3` → `math.isclose()` 로 비교
- **나눗셈** → `7 / 2` = 3.5(float), `7 // 2` = 3, `-7 // 2` = −4 (내림)
- ⚠ `bool("0")` 은 **True** — 빈 문자열만 False

### 3교시 · 연산자와 비트 연산

**키워드**: `단축 평가`, `& | ^ ~ << >>`, `마스크 4패턴`, `바이트 분리 · 결합`, `and vs &`

**개요**: 비트 마스크 4패턴(읽기 · 설정 · 해제 · 토글)으로 8비트 레지스터를 다루고, 16비트 센서 값을 두 바이트로 나누고 합친다.

**핵심 내용**

#### 마스크 4패턴
> `reg & (1 << n)` 읽기 · `reg |= (1 << n)` 설정 · `reg &= ~(1 << n)` 해제 · `reg ^= (1 << n)` 토글
- **8비트로 자르기** → `~x & 0xFF` (Python int 는 무한 자릿수라 `~` 결과가 음수)
- **16비트 분리** → `hi = v >> 8`, `lo = v & 0xFF` · **결합** → `(hi << 8) | lo`
- ⚠ `and` 는 논리(참/거짓), `&` 는 비트 — `6 and 3` = 3, `6 & 3` = 2

### 4교시 · 조건문

**키워드**: `if / elif / else`, `들여쓰기`, `truthy / falsy`, `in`, `조건 표현식`

**개요**: 처음 참인 블록 하나만 실행. 범위 비교 `0 <= x < 10` 과 `in` 을 쓰고, 임계값으로 센서 상태를 판정한다.

**핵심 내용**

#### 조건문 규칙
- **처음 참인 블록 하나만** → 순서가 판정 결과를 바꾼다
- **거짓으로 평가** → `0` · `""` · `[]` · `None`
- **범위** → `18 <= temp < 26` · **포함** → `x in (1, 2, 3)`
- **한 줄 if** → `"HIGH" if t > 30 else "OK"`
- ⚠ 조건엔 `==` (대입 `=` 아님), 블록은 들여쓰기로 구분

### 5교시 · 반복문

**키워드**: `for`, `while`, `range()`, `break`, `continue`, `반복문 else`, `enumerate`, `zip`

**개요**: `range(start, stop, step)` 으로 for, 조건으로 while. 반복문의 `else` 는 break 없이 끝났을 때만 실행. `enumerate` · `zip` 으로 인덱스와 여러 시퀀스를 함께.

**새로 나온 함수**
| 함수 | 기본형 | 용도 |
|---|---|---|
| `range()` | `range(0, 256, 64)` | 0, 64, 128, 192 — stop 은 포함 안 함 |
| `enumerate()` | `for i, v in enumerate(xs):` | 인덱스와 값 함께 |
| `zip()` | `for a, b in zip(xs, ys):` | 여러 시퀀스를 나란히 (짧은 쪽에서 끝) |

**핵심 내용**

#### 흐름 제어
- **`break`** → 즉시 탈출, **`continue`** → 다음 반복으로
- **`while … else`** → break 없이 끝났을 때만 else
- **무한 루프** → 셀 왼쪽 ■ 로 중지

### 6교시 · 문자열 처리

**키워드**: `인덱싱`, `슬라이싱`, `불변`, `split`, `strip`, `join`, `파싱`, `repr`

**개요**: 슬라이싱으로 부분 문자열, 메서드로 가공. 문자열은 불변이라 메서드는 새 문자열을 돌려준다. 시리얼 수신 프레임을 분리 · 검증 · 형변환하는 파싱 파이프라인.

**새로 나온 함수**
| 함수 | 기본형 | 용도 |
|---|---|---|
| `split()` | `"T:25.3,H:60".split(",")` | 구분자로 나눠 리스트 |
| `strip()` | `line.strip()` | 앞뒤 공백 · 개행 제거 |
| `join()` | `",".join(parts)` | 리스트를 구분자로 이어 붙임 |
| `repr()` | `repr(s)` | `\r\n` 같은 보이지 않는 문자까지 표시 |

**핵심 내용**

#### 슬라이싱
> `s[start:stop:step]` — stop 은 포함 안 함
- `s[-3:]` 끝 3글자 · `s[::-1]` 뒤집기 · 범위 밖 슬라이스는 오류 없이 빈 문자열(인덱스는 IndexError)

#### 파싱 파이프라인
- **strip → split → 필드 검사 → float()** → 손상 프레임은 걸러냄
- ⚠ 수신 줄 끝의 `\r\n` → `repr()` 로 확인 후 `strip()`
