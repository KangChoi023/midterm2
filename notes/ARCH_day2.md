## Day 2 — 컴퓨터 속 모든 것은 숫자다

### 1교시 · 브리지

**키워드**: `ON/OFF`, `1과 0`, `8칸`

**개요**: 부품 안의 전기는 켜짐 · 꺼짐 두 상태뿐. 켜짐 = 1, 꺼짐 = 0 으로 적으면 여덟 칸이 여덟 자리 숫자가 된다. 오늘의 모든 것은 이 여덟 칸 위에서 일어난다.

**핵심 내용**

#### 두 상태 = 두 숫자
> 전기가 흐른다(1) / 흐르지 않는다(0) — 중간은 없다
- **켜짐** → 1, **꺼짐** → 0
- **여덟 칸** → 왼쪽부터 읽은 8자리 (예: `01101001`)
- ⚠ 읽는 방향은 왼쪽부터 — 틀리면 방향부터 의심

### 2교시 · 자릿값과 변환

**키워드**: `자릿값`, `2진수`, `10진수`, `검산`

**개요**: 10진수는 자리마다 10배, 2진수는 자리마다 2배. 2→10 은 켜진 자리 더하기, 10→2 는 큰 자릿값부터 덜어내기. 반대로 되돌려 검산까지가 한 문제.

**핵심 용어**
- **2진수(binary)**: 0 과 1 만 쓰고 자리마다 2배가 되는 수. 8칸의 자릿값 128 64 32 16 8 4 2 1
- **자릿값(place value)**: 그 자리의 숫자 1 이 뜻하는 크기

**핵심 내용**

#### 8칸의 자릿값
> `128 64 32 16 8 4 2 1` — 이 표 하나로 변환 끝
- **2진 → 10진** → 1 인 자리의 자릿값을 더한다 — `01100100` = 64 + 32 + 4 = **100**
- **10진 → 2진** → 128 부터 "들어가나?" 물어 들어가면 1, 아니면 0 — 167 → `10100111`
- **검산** → 바꾼 방향의 반대로 한 번 더
- ⚠ 2진수는 8칸짜리 방 — `110100` 이 아니라 `00110100` (빈 칸도 0)

### 3교시 · 비트와 바이트

**키워드**: `비트(bit)`, `바이트(byte)`, `KB`, `MB`, `GB`, `1024`

**개요**: 한 칸이 비트, 8비트가 1바이트. 바이트 → KB → MB → GB 는 1,024 배씩 커지는 사다리.

**핵심 용어**
- **비트(bit)**: 0 또는 1 을 담는 가장 작은 칸
- **바이트(byte)**: 8비트 묶음. 영문 글자 하나가 사는 크기

**핵심 내용**

#### 단위 사다리
> 비트 ×8 → 바이트 ×1024 → KB ×1024 → MB ×1024 → GB
- **유일한 예외** → 비트 → 바이트만 ×8, 나머지는 ×1,024 (10 이 아니다)
- **일상 크기** → 문서 30KB · 사진 4MB · 노래 8MB · 영화 4GB
- **8GB 메모리** → 약 687억 개의 칸 (8 × 1024³ × 8 비트)

### 4교시 · 정수의 구조

**키워드**: `0~255`, `오버플로우`, `부호 비트`, `2의 보수`, `-128~127`

**개요**: 1바이트 정수는 0~255. 255 다음은 0 으로 되감긴다(넘침). 음수는 맨 앞 칸을 부호로 쓰고, 0 에서 뒤로 되감은 자리로 만든다 — 2의 보수.

**핵심 용어**
- **오버플로우(overflow, 넘침)**: 칸 수로 담을 수 있는 범위를 넘어 처음으로 되감기는 것
- **부호 비트(sign bit)**: 맨 앞 칸. 0 이면 양수, 1 이면 음수
- **2의 보수(two's complement)**: 0 에서 되감은 자리로 음수를 나타내는 약속. `-1` = `11111111`

**핵심 내용**

#### 칸 수가 한계를 정한다
> 8칸 → 부호 없음 0~255 · 부호 있음 -128~127
- **255 + 1** → 0 (부호 없는 넘침)
- **127 + 1** → -128 — `01111111` → `10000000` (부호가 뒤집힘)
- **-1** → `11111111`, **-5** → 0 에서 다섯 칸 뒤
- ⚠ 갑자기 음수가 되는 사고의 정체 = 넘침

### 5교시 · ASCII

**키워드**: `ASCII`, `A = 65`, `a = 97`, `차이 32`

**개요**: 컴퓨터는 글자를 모른다 — 글자마다 번호를 붙인 약속표가 ASCII. 글자 → 번호 → 8칸 2진수. 글자 하나 = 1바이트.

**핵심 용어**
- **ASCII**: 영문 · 숫자 · 기호에 0~127 번호를 붙인 문자 약속표

**핵심 내용**

#### 글자에서 8칸까지
> 글자 → 번호 → 2진수 (`K` → 75 → `01001011`)
- **대문자** → 64 + 알파벳 순번 (A = 65, K = 75)
- **소문자** → 대문자 + 32 (a = 97) — 8칸 중 **한 칸(32 자리)만** 다르다
- **이름 세 글자** → 3바이트

**연결**
- [C D2·5교시 문자열](#/c/2/5) — 문자열 = ASCII 바이트의 줄 + `'\0'`

### 6교시 · RGB

**키워드**: `RGB`, `빛의 삼원색`, `채널 0~255`, `픽셀 3바이트`

**개요**: 화면의 색은 빨강 · 초록 · 파랑 빛의 조합. 채널 하나가 1바이트(0~255)라 색 하나 = 숫자 셋 = 3바이트.

**핵심 용어**
- **RGB**: 빨강(R) · 초록(G) · 파랑(B) 빛의 세기로 색을 나타내는 방식. 각 0~255
- **픽셀(pixel)**: 화면을 이루는 점 하나. RGB 3바이트

**핵심 내용**

#### 색 = 숫자 셋
> (R, G, B) 각 1바이트 — 예 (255, 107, 0)
- **빛은 섞을수록 밝아진다** → 빨강 + 초록 = 노랑, 셋 다 = 흰색 (물감과 반대)
- **숫자만 같으면 같은 색** → 숫자가 곧 색
- **사진 크기** → 픽셀 수 × 3바이트 → MB 단위

### 7교시 · 16진수

**키워드**: `16진수`, `0~F`, `4비트 = 1글자`, `#FF6B00`

**개요**: 8칸은 읽기 길다. 4칸씩 갈라 한 글자(0~9, A~F)로 적는 줄임 표기가 16진수 — 새 계산이 아니라 새 읽기.

**핵심 용어**
- **16진수(hexadecimal)**: 0~9, A~F 열여섯 글자로 쓰는 수. 한 글자 = 4비트, 두 글자 = 1바이트

**핵심 내용**

#### 4칸 = 1글자
> `0100 1011` → `4B`
- **1011** → B, **1111** → F
- **색상 코드** → `#FF6B00` = R `FF`(255) · G `6B`(107) · B `00`(0)
- **같은 수, 다른 표기** → 100 = `01100100` = `0x64`

### 8교시 · 종합

**키워드**: `데이터 카드`, `메모리 한 줄`

**개요**: 내 정수 · 이니셜 · 색을 10진 · 2진 · 16진으로 모은 "나의 데이터 카드". 이름표를 지우면 문자도 색도 정수도 똑같은 8칸 — 무엇인지는 읽는 규칙이 정한다.

**핵심 내용**

#### 하루 정리
> 컴퓨터 속의 모든 것은 숫자다
- 2진수 · 자릿값 → 비트/바이트 · 단위 → 정수(넘침 · 2의 보수) → 문자(ASCII) → 색(RGB) → 16진수
- **같은 8칸, 다른 해석** → `01001011` 은 75 도, `K` 도 될 수 있다
