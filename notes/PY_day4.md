## Day 4 — NumPy·pandas 입문 및 미니 프로젝트

### 1교시 · NumPy 기초 — 벡터 연산·브로드캐스팅

**키워드**: `ndarray`, `shape`, `dtype`, `벡터 연산`, `브로드캐스팅`

**개요**: 리스트는 객체 참조의 목록, ndarray 는 같은 자료형이 한 줄로 붙은 메모리. 반복문 없이 배열 전체에 연산하고(벡터 연산), 모양이 다르면 규칙에 맞게 늘려서(브로드캐스팅) 계산한다.

**핵심 용어**
- **ndarray**: NumPy 배열. 같은 dtype 의 값이 연속된 메모리에 놓인다
- **shape**: 각 축의 길이 — `(2, 3)` = 2행 3열
- **브로드캐스팅(broadcasting)**: 모양이 다른 배열끼리 연산할 때 길이 1(또는 없는) 축을 늘려 맞추는 규칙

**새로 나온 함수**
| 함수 | 기본형 | 용도 |
|---|---|---|
| `np.array()` | `a = np.array([1, 2, 3])` | 리스트 → ndarray |
| `np.arange()` · `np.zeros()` | `np.zeros((2, 3))` | 범위 · 0 으로 채운 배열 |

**핵심 내용**

#### 같은 기호, 다른 의미
> 리스트 `[1,2] * 2` = `[1,2,1,2]` · 배열 `np.array([1,2]) * 2` = `[2, 4]`
- **속도** → 반복문 대신 벡터 연산이 수십 배 빠름

#### 브로드캐스팅
- **스칼라** → 모든 칸에 퍼짐
- **`(2,3) + (3,)`** → 행마다 더해짐
- ⚠ 뒤 축부터 비교해 길이가 같거나 1 이어야 — 아니면 ValueError

### 2교시 · NumPy 활용 — 마스크·통계·이미지=배열

**키워드**: `뷰(view)`, `copy()`, `불리언 마스크`, `mean · max · argmax`, `이미지 = H×W 배열`

**개요**: 슬라이스는 원본을 공유하는 뷰 — 고치면 원본도 바뀐다. 조건식으로 만든 불리언 마스크로 골라내고, 통계 함수로 집계. 이미지는 H×W(×3) 숫자 배열.

**새로 나온 함수**
| 함수 | 기본형 | 용도 |
|---|---|---|
| `np.mean()` · `np.max()` | `a.mean()` · `a.max(axis=0)` | 평균 · 최댓값 (축 지정) |
| `np.argmax()` | `a.argmax()` | 최댓값의 위치(인덱스) |
| `ndarray.copy()` | `b = a[1:3].copy()` | 뷰가 아닌 독립 복사 |

**핵심 내용**

#### 슬라이스는 뷰
> Day 2 의 참조 모델이 배열에서 다시
- ⚠ `b = a[1:3]; b[0] = 99` → a 도 바뀐다 → 독립이 필요하면 `.copy()`

#### 마스크로 고르기
- **`m = temps > 30`** → True/False 배열
- **`temps[m]`** → 조건 맞는 값만 · **`m.sum()`** → 몇 건 · **`np.where(m)`** → 어디서

### 3교시 · Matplotlib — 시계열·히스토그램

**키워드**: `plt.plot`, `axhline`, `hist`, `title · xlabel · ylabel · grid`, `savefig`

**개요**: 읽히는 그래프 4요소 — 제목 · x축 · y축 이름 · 격자(+범례). 시계열에 임계선과 경보 지점을 표시하고, 히스토그램으로 분포를 본다. 저장은 `savefig` 를 `show` 앞에.

**새로 나온 함수**
| 함수 | 기본형 | 용도 |
|---|---|---|
| `plt.plot()` | `plt.plot(t, temps, label="temp")` | 선 그래프 (시계열) |
| `plt.axhline()` | `plt.axhline(30, color="r", ls="--")` | 가로 임계선 |
| `plt.hist()` | `plt.hist(temps, bins=20)` | 히스토그램 — 분포 |
| `plt.savefig()` | `plt.savefig("report.png", dpi=150)` | 파일 저장 |

**핵심 내용**

#### 그래프 체크리스트
- **4요소** → `title` · `xlabel` · `ylabel` · `grid(True)` (+ `legend`)
- ⚠ `savefig` 를 `show` 뒤에 부르면 빈 그림이 저장된다

### 4교시 · pandas 맛보기 — DataFrame·groupby·CSV

**키워드**: `DataFrame`, `head · info · describe`, `필터`, `groupby`, `read_csv · to_csv`, `결측`

**개요**: DataFrame 은 dict 레코드 목록의 완성형 표. NumPy 마스크와 같은 문법으로 거르고, groupby 로 분할 · 집계 · 결합을 한 줄에. CSV 왕복과 결측값(NaN) 처리.

**새로 나온 함수**
| 함수 | 기본형 | 용도 |
|---|---|---|
| `pd.DataFrame()` | `df = pd.DataFrame(records)` | dict 목록 → 표 |
| `df.groupby()` | `df.groupby("node")["temp"].mean()` | 그룹별 집계 |
| `pd.read_csv()` · `df.to_csv()` | `df.to_csv("log.csv", index=False)` | CSV 읽기 · 쓰기 |

**핵심 내용**

#### 표 다루기 3종 세트
> `head()` 앞부분 · `info()` 열과 자료형 · `describe()` 통계 요약
- **필터** → `df[df["temp"] > 30]` (마스크와 같은 문법)
- **groupby** → 분할 → 집계 → 결합을 한 줄
- ⚠ `to_csv` 에 `index=False` 를 빼면 인덱스 열이 하나 더 저장된다

### 5교시 · 파이썬 문법 마무리 — 제너레이터·이터레이터

**키워드**: `이터레이터`, `한 번 소모`, `yield`, `제너레이터`, `제너레이터 표현식`

**개요**: 이터레이터는 한 번 다 돌면 소모된다(Day 2 map 의 정체). `yield` 로 값을 하나씩 내주는 제너레이터는 스트림 수신부에 딱 — readline 이 yield 였던 것.

**핵심 용어**
- **이터레이터(iterator)**: `next()` 로 하나씩 꺼내는 객체. 다 꺼내면 끝(재사용 불가)
- **제너레이터(generator)**: `yield` 가 있는 함수. 호출하면 값을 하나씩 내주는 이터레이터가 된다

**핵심 내용**

#### 제너레이터 수신부
> `def read_frames(src): for line in src: … yield frame`
- **필요할 때 하나씩** → 메모리에 전부 올리지 않음 — 끝없는 시리얼 스트림에 적합
- **표현식** → `(x * 2 for x in xs)` — 대괄호 대신 괄호
