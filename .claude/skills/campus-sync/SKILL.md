# 강의자료 정리 (PC)

사용자는 경영학 전공 · 코딩 초보다. 한국어로, 무엇을 왜 하는지 쉬운 말로 짧게 설명한다.
정리 규칙은 `tools/sync_campus.py` 맨 위 설명에 있다 — Day 폴더마다 `1. 강의 노트` · `2. 애니메이션` · `3. 교안` · `4. 워크시트` · `5. 실습 코드` · `6. 참고` · `7. 내 자료` · `_원본`.

## 순서
1. **이 저장소 최신화** — 정리 규칙 · Day 제목(노트)이 GitHub 에서 바뀌었을 수 있다.
   `git -C <이 저장소> pull --ff-only` — 실패하면(내 PC 에서 고친 파일 등) 멈추고 상황을 설명한다.
2. **Python 확인** — `py -V` → 없으면 `python -V` → `python3 -V`. 아래 `py` 는 찾은 것으로 바꾼다.
3. **미리 보기** — `py -X utf8 tools/sync_campus.py --dry-run`
   - 출력 둘째 줄 `내 폴더: …` 경로를 사용자에게 보여 주고 맞는지 확인한다 (바탕화면 아래에서 `06_HyundaiAI` 를 자동으로 찾는다). 다르면 `--dest "<맞는 경로>"` 를 붙인다.
   - `! 예전 방식으로 정리된 폴더가 …` → 옮겨질 목록을 보여 주고, 동의하면 `--migrate` 를 붙인다 (지우지 않고 과목 폴더 안 `_예전정리/` 로 옮김).
   - `■ 내가 모아 둔 자료 N개` → 사용자가 직접 모은 파일(이름에 DayN: 날짜 붙은 교안 · 퀴즈 · 판서 · 풀이 노트북 …)을 그 Day 폴더의 `7. 내 자료/` 로 옮길 수 있다. 목록을 보여 주고, 동의하면 `--mine` 을 붙인다. 강사님 파일과 똑같은 것(중복 표시)은 `_예전정리/` 로 간다.
   - `⚠ 과목을 모르는 자료` → 새 과목이다. 사용자에게 과목 폴더 이름(기존 번호 다음, 예: `11_…`)과 파일 이름에 쓸 과목명을 묻고 `--add "앞부분=과목폴더=과목명"` 을 붙인다. 앞부분 = 강사님 폴더 이름에서 `-dayN` 앞 (소문자, 예: `Vision-day1` → `vision`).
     같은 과목을 매번 `--add` 하지 않도록, 클라우드에서 과목 추가 PR 이 올라와 Merge 되면 1번의 pull 로 규칙이 들어온다.
4. **실행** — 3번과 같은 명령에서 `--dry-run` 만 뺀다.
5. **보고** — 새로 생긴 · 바뀐 Day 폴더와 1~4번 파일을 짧은 표로. `_원본/` 개수는 한 줄로. 바뀐 파일은 옛 판이 그 Day 폴더의 `_이전판/` 에 있다고 알려 준다. `이름 바꿈: 옛 → 새` 줄은 번호 규칙이 바뀌어 이름만 고친 것(복사 · 삭제 없음)이라 개수만 한 줄로.

## 하지 않는 것
- 파일 · 폴더 삭제, 프로그램이 하지 않는 수동 이동 · 이름 바꾸기 (사용자가 직접 요청할 때만).
- 이 저장소 파일 수정 · 커밋 · push — 정리 규칙을 바꾸고 싶다는 요청은 클라우드 세션에서 PR 로 하자고 안내한다.
